# Conexión Vital

Blog educativo en español sobre alteraciones cardiovasculares y respiratorias. Diseño adaptable a móviles y computadoras, con buscador, filtros por sistema y fichas interactivas.

## Archivos
- `index.html`: estructura del sitio y título “Conexión Vital”.
- `styles.css`: diseño visual y adaptación a pantallas.
- `script.js`: fichas, búsqueda y filtros.
- `README.md`: instrucciones.

## Publicación gratuita en GitHub Pages desde Android
1. Descarga y extrae este ZIP en tu teléfono.
2. En GitHub, crea un repositorio público nuevo llamado `conexion-vital`.
3. Abre el repositorio y usa **Agregar archivo → Cargar archivos**.
4. Sube `index.html`, `styles.css`, `script.js` y `README.md` directamente a la raíz (no subas solo el ZIP).
5. Confirma con **Confirmar cambios**.
6. En el repositorio, abre **Configuración → Páginas**.
7. En la sección de implementación, elige **Implementar desde una rama**, selecciona la rama `main` y la carpeta raíz (`/(root)`), y pulsa **Guardar**.
8. Espera a que GitHub Pages publique el sitio. El enlace suele tener la forma `https://TU-USUARIO.github.io/conexion-vital/`. Reemplaza `TU-USUARIO` por tu nombre de usuario real.

## Aviso
Material educativo general. No sustituye la evaluación, el diagnóstico ni el tratamiento profesional.
